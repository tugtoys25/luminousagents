# Dashboard UI guide

The staff dashboard is under `/dashboard`. All staff pages and APIs must require a verified Cloudflare Access identity and enforce role and record-level authorization on the server. Hiding controls in the UI is not authorization. Brokers must only read or mutate opportunities assigned to them. Editors manage content; publishers approve publication; admins manage access and document release. All consequential actions must create append-only audit events. Use shared navigation and external CSS; do not add inline styles that conflict with the CSP. E2E acceptance: unauthenticated access denied, role matrix enforced per route, assigned broker boundary enforced, keyboard navigation and responsive layouts verified.
