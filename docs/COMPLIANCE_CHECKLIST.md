# Compliance checklist — release evidence required

- [ ] Counsel approves privacy notice, terms, NDA, retention schedule, cross-border processing and electronic-signature method.
- [ ] Data inventory, purpose, lawful basis, retention and deletion process approved by responsible privacy/legal owner.
- [ ] Staff access matrix and least privilege reviewed.
- [ ] Buyer consent and NDA template version/hash captured.
- [ ] Security incident response and breach escalation contacts confirmed.
- [ ] R2/D1/KV backup access and retention reviewed.
- [ ] All 198 imported opportunities individually reviewed; prohibited/unsupported claims removed; none public before approval.
- [ ] Evidence retained for scanner, authorization, restore, accessibility, load and penetration/security regression tests.

This checklist is operational guidance, not legal advice or a declaration of compliance.
